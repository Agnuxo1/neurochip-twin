# Judge demo storyboard

The generated demo is an English, captioned walkthrough that lasts 107 seconds,
well below the competition's five-minute limit. It uses a locally generated
synthetic movie and committed aggregate evidence; no third-party dataset images
or per-image predictions are embedded.

Regenerate the synthetic benchmark if needed, then render the demo:

```bash
python -m src.neurochip_twin --out outputs/demo --seed 42 --samples 180 --scenario compound_specific
python scripts/make_demo_video.py
```

The renderer writes `outputs/demo/neurochip_twin_judges_demo.mp4` and a matching
`.srt` caption file. It requires OpenCV and Pillow from `requirements.txt`.

| Time | Scene | Evidence and boundary |
|---|---|---|
| 0:00–0:10 | Opening time-lapse | Generated synthetic frames, explicitly labelled synthetic. |
| 0:10–0:25 | Analysis path | Image input → segmentation → association → interpretable trajectories → readout. |
| 0:25–0:43 | Synthetic benchmark | Static 0.567, physics-only 0.692, temporal 0.968, additive multimodal 0.990 ROC-AUC; controlled generator stress test only. |
| 0:43–1:03 | Real OoC image-quality audit | 3,072 expert good/bad quality labels, six non-neural cell-line folds; Inception-v3 plus metadata macro ROC-AUC 0.773. This is sample-quality triage, not response prediction. |
| 1:03–1:17 | BBBC038 microscopy audit | 12 calibration and 24 held-out images; pixel IoU 0.520 and Dice 0.575. Nuclei-segmentation portability only. |
| 1:17–1:32 | Inspectable outputs | Prediction CSV, flow counterfactual, calibration curve and HTML summary; uncertainty is a threshold-distance proxy. |
| 1:32–1:47 | Reproduction and limitations | CPU reproduction command, tests, public report and the missing authorized neural OoC response validation. |

The separate OoC quality audit's aggregate-only scores are generated by
`scripts/export_ooc_quality_summary.py` from local audit outputs. Its public
JSON omits images, per-image predictions and model weights. The image archive
and the datasheet paper state conflicting licenses; the discrepancy remains
disclosed and unresolved. Do not redistribute the source images.
